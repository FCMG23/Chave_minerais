## 📌 Sobre o projeto

Esta aplicação foi desenvolvida para auxiliar na **identificação macroscópica de minerais** (ou seja, a olho nu), sendo voltada para:

* 🎓 Estudantes de Geociências
* 🧪 Professores e pesquisadores
* ⛏️ Entusiastas da mineralogia

A ferramenta permite identificar **mais de 100 minerais**, utilizando um **fluxo guiado baseado em propriedades físicas observáveis**.

## ⚙️ Como funciona

A aplicação conduz o usuário por uma sequência de decisões, simulando uma **chave dicotômica digital**.

### ✨ Fluxo – Brilho não metálico

1. Tipo de brilho (não metálico)
2. Cor (clara ou escura)
3. Dureza relativa
4. Clivagem (presente ou ausente)
5. Densidade (leve ou pesado)
